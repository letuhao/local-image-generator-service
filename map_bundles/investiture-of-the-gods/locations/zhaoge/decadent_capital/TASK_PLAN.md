# Triều Ca (Chào Ca) Asset Generation Plan

## Project Overview
Generate **9 categories of assets** for the decadent_capital location bundle, based on Fengshen Yanyi lore and the shang_capital biome definition.

---

## Location Profile: Triều Ca (Zhaoge/朝歌)

### Visual Identity
- **Atmosphere**: Opulent yet decaying, oppressive grandeur,盛衰交 thoa (prosperity and decline intertwined)
- **Color Palette**: Gold (#D4AF37), Crimson (#DC143C), Bronze (#CD7F32), Dark Shadows (#1A1A2E), Jade Green (#00A86B)
- **Architectural Style**: Shang dynasty elements (bronze motifs, rammed earth walls, tiered platforms) + xianxia fantasy (floating aura, divine aura, mystical elements)
- **Key Materials**: Bronze, jade, crimson lacquer, golden roof tiles, weathered stone, decaying wood

### Key Landmarks
1. **Lộc Đài (鹿臺/Deer Terrace)** - Massive artificial terrace with multi-tiered pavilions
2. **Hiên Viên Phần (軒轅殿/Xuanyuan Hall)** - Where Di Ji transforms into a fox spirit
3. **Phiêu Phúc Các (嫔福閣/Phoenix Pavilion)** - Opulent pleasure palaces
4. **Tây Hoa Cung (西宮/West Palace)** - Daji's domain
5. **Mục Dã Lâu (鹿臺/Deer Tower)** - Observation towers

## Generation Notes

### Consistent Style Guidelines
- All terrain: orthographic top-down, seamless edges
- All structures/dwellings: 2.5D sprite angle (~30° tilt)
- All artifacts: centered composition, dramatic rim light
- All flora: single sprite, clean alpha background
- All VFX: translucent overlay, seamless tiling
- All creatures: 2.5D sprite, readable silhouette
- All arrays: top-down/isometric tile, seamless
- All vehicles: 2.5D sprite angle, dynamic pose

### Color Palette Reference
| Element | Hex | Usage |
|---------|-----|-------|
| Imperial Gold | #D4AF37 | Roofs, accents, divine elements |
| Crimson | #DC143C | Pillars, lanterns, silk, walls |
| Bronze | #CD7F32 | Doors, fittings, ritual objects |
| Jade Green | #00A86B | Spirit elements, fox eyes |
| Dark Shadow | #1A1A2E | Oppressive areas, corruption |
| Mist Purple | #6A5ACD | VFX, decadent atmosphere |
| Bone White | #F5F5DC | Underworld, ghostly elements |

### Fengshen Yanyi Canon References
- Lộc Đài built by Di Xin for indulgence
- Hiên Viên Phần where Di Ji transforms
- Daji's West Palace domain
- Fox spirit artifacts and wards
- Bronze ritual objects (zun, ding)
- Imperial seal of Shang Dynasty
